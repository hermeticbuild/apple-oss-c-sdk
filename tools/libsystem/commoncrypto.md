# CommonCrypto linker interface

The macOS 26.5 release lock can specify `commoncrypto_source`, a relative
path to Apple CommonCrypto-600035. The offline [recipe](commoncrypto.py)
pins the [reviewed source inputs](data/macosx26.5/commoncrypto.json).
Apple's macOS dynamic target builds `/usr/lib/system/libcommonCrypto.dylib`
and sets `EXPORTED_SYMBOLS_FILE` to a per-architecture file generated by
preprocessing `exports.exp-in`. The pinned input contains 245 unconditional
names. The recipe emits link metadata for those names. It reads the four
constant definitions to identify data exports. [Apple's Xcode target and
build rule](https://github.com/apple-oss-distributions/CommonCrypto/blob/a0ac082c490b65585ade764511acfdbf1d97bc5e/CommonCrypto.xcodeproj/project.pbxproj) ·
[Published export list](https://github.com/apple-oss-distributions/CommonCrypto/blob/a0ac082c490b65585ade764511acfdbf1d97bc5e/exports.exp-in)

The public install phases select eight headers. Those headers declare 54
default exports. The target's TAPI flag `COMMON_DIGEST_FOR_RFC_1321` selects
the `MD5Final` compatibility declaration. The other 190 exports have
declarations in private install headers. The link metadata includes the full
published export list while the C installation keeps its existing public
header inventory.

Verify the offline recipe with the pinned checkout.

```sh
LIBSYSTEM_TEST_COMMONCRYPTO="$COMMONCRYPTO_SOURCE" \
  python3 -m unittest tools.libsystem.test_commoncrypto
```

The macOS 26.5.2 runtime on build 25F84 supplies independent export-kind
evidence. Inspect the export trie, image UUID and Mach-O section ranges.

```sh
image=/usr/lib/system/libcommonCrypto.dylib
xcrun dyld_info -arch arm64e -uuid -load_commands -exports "$image"
xcrun dyld_info -arch x86_64 -dyld_cache_path "$X86_64_CACHE" \
  -uuid -load_commands -exports "$image"
```

For each architecture, add the export-trie offset to the `__TEXT` segment's
VM address and locate the resulting address in its Mach-O section. All 241
function exports land in the instructions section. The four data exports
are `CCrfc3394_iv`, `CCrfc3394_ivLen`, `kCCRandomDefault`, and
`kCCRandomDevRandom`. All 245 are strong definitions. The build checks the source-derived symbol
kinds against a digest shared by the two observed runtime slices. The generated
stub and the macOS 26.5 SDK both bind the 245 names through libSystem for arm64
and x86_64 at deployment minima 11.0 and 26.5. These link probes use the
26.5 SDK at both minima.
